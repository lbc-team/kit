在前一篇文章中，我们构建了一个已签名的交易来创建一个 Solana token。现在，让我们看看如何发送此交易并确保它已获得网络的确认。

## 发送交易而不确认

发送交易最常见的方式是通过 `sendTransaction` RPC 方法。此方法接受编码后的签名交易，并将其转发到配置的 RPC 节点，以便它可以为我们处理。

一种解决办法是使用 `getBase64EncodedWireTransaction` 对交易进行编码，并将其传递给 `sendTransaction` RPC 方法，如下所示。

```ts twoslash
import { FullySignedTransaction, TransactionWithBlockhashLifetime, Rpc, SolanaRpcApi } from "@solana/kit";
const signedTransaction = null as unknown as FullySignedTransaction & TransactionWithBlockhashLifetime;
const rpc = null as unknown as Rpc<SolanaRpcApi>;
// ---cut-before---
import { getBase64EncodedWireTransaction } from "@solana/kit";

const encodedTransaction = getBase64EncodedWireTransaction(signedTransaction);
await rpc.sendTransaction(encodedTransaction, { preflightCommitment: "confirmed", encoding: "base64" }).send();
```

然而，Kit 提供了一个辅助函数，它为我们完成了这项工作，同时提供了一些合理的默认值。这个函数叫做 `sendTransactionWithoutConfirmingFactory`，给定一个 RPC 对象，它返回一个发送交易而不等待确认的函数。

```ts twoslash
import { FullySignedTransaction, TransactionWithBlockhashLifetime, Rpc, SolanaRpcApi } from "@solana/kit";
const signedTransaction = null as unknown as FullySignedTransaction & TransactionWithBlockhashLifetime;
const rpc = null as unknown as Rpc<SolanaRpcApi>;
// ---cut-before---
import { sendTransactionWithoutConfirmingFactory } from "@solana/kit";

const sendTransaction = sendTransactionWithoutConfirmingFactory({ rpc });
await sendTransaction(signedTransaction, { commitment: "confirmed" });
```

## 确认策略

发送交易是一回事，但通常情况下，我们希望确保它们已被网络处理，然后再继续执行我们的应用程序逻辑。

有几种方法可以确保交易已获得网络的确认。例如，我们可以定期轮询网络以检查交易的状态，直到它达到所需的 commitment level。另一种方法是监听网络事件，并使用它们来确定已发送交易的状态。

有时，深入研究确认策略并创建最适合我们应用程序的自定义策略可能很有用。但在所有其他情况下，Kit 提供了辅助函数，可以消除这种复杂性。即，它提供了两个辅助函数，它们都发送和确认交易。要使用哪个函数取决于交易中设置的 lifetime。

- `sendAndConfirmTransactionFactory`  用于使用 blockhash 策略作为其 lifetime 的交易。
- `sendAndConfirmDurableNonceTransactionFactory` 用于使用 durable nonce 策略作为其 lifetime 的交易。

两者都接受 RPC 和 RPC Subscriptions 对象，并返回一个为我们发送和确认交易的函数。由于我们在本教程中使用的是 blockhash 策略，因此我们将使用 `sendAndConfirmTransactionFactory` 函数。

```ts twoslash
import {
  FullySignedTransaction,
  TransactionWithBlockhashLifetime,
  Rpc,
  SolanaRpcApi,
  RpcSubscriptions,
  SolanaRpcSubscriptionsApi,
} from "@solana/kit";
const signedTransaction = null as unknown as FullySignedTransaction & TransactionWithBlockhashLifetime;
const rpc = null as unknown as Rpc<SolanaRpcApi>;
const rpcSubscriptions = null as unknown as RpcSubscriptions<SolanaRpcSubscriptionsApi>;
// ---cut-before---
import { sendAndConfirmTransactionFactory } from "@solana/kit";

const sendAndConfirmTransaction = sendAndConfirmTransactionFactory({ rpc, rpcSubscriptions });
await sendAndConfirmTransaction(signedTransaction, { commitment: "confirmed" });
```

## 交易签名

如果将鼠标悬停在上面的 `sendTransaction` 或 `sendAndConfirmTransaction` 函数上，您会注意到它们的返回类型只是 `Promise<void>`。也就是说，它们不返回交易签名，而该签名在网络上唯一标识该交易。

这是因为存在一个常见的误解，即必须等待交易发送到网络才能获得其签名。然而，事实并非如此。一旦交易由其 fee payer 签名，就可以访问交易签名。这是因为唯一标识交易的签名不是其他，正是该交易的 fee payer 的签名。

因此，Kit 通过提供一个 `getSignatureFromTransaction` 函数来分离这两个不同的概念，该函数返回一个交易的签名，即使在将其发送到网络之前也可以使用该签名。

```ts twoslash
import {
  FullySignedTransaction,
  TransactionWithBlockhashLifetime,
  Rpc,
  SolanaRpcApi,
  RpcSubscriptions,
  SolanaRpcSubscriptionsApi,
} from "@solana/kit";
const signedTransaction = null as unknown as FullySignedTransaction & TransactionWithBlockhashLifetime;
const rpc = null as unknown as Rpc<SolanaRpcApi>;
const rpcSubscriptions = null as unknown as RpcSubscriptions<SolanaRpcSubscriptionsApi>;
// ---cut-before---
import { getSignatureFromTransaction, sendAndConfirmTransactionFactory } from "@solana/kit";

// 访问交易签名。
const signature = getSignatureFromTransaction(signedTransaction);

// 发送并确认交易。
const sendAndConfirmTransaction = sendAndConfirmTransactionFactory({ rpc, rpcSubscriptions });
await sendAndConfirmTransaction(signedTransaction, { commitment: "confirmed" });
```

## 更新 `client.ts`

掌握了所有这些新知识后，让我们更新我们的 `Client` 对象，以包含从 `sendAndConfirmTransactionFactory` 辅助函数创建的新 `sendAndConfirmTransaction` 函数。

```ts twoslash title="src/client.ts"
import {
  CompilableTransactionMessage,
  MessageSigner,
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
  TransactionSigner,
} from "@solana/kit";
const rpc = null as unknown as Rpc<SolanaRpcApi>;
const rpcSubscriptions = null as unknown as RpcSubscriptions<SolanaRpcSubscriptionsApi>;
const wallet = null as unknown as TransactionSigner & MessageSigner;
const estimateAndSetComputeUnitLimit = null as unknown as <T extends CompilableTransactionMessage>(
  transactionMessage: T,
) => Promise<T>;
// ---cut-before---
import {
  sendAndConfirmTransactionFactory, // [!code ++]
  // ...
} from "@solana/kit";

export type Client = {
  estimateAndSetComputeUnitLimit: <T extends CompilableTransactionMessage>(transactionMessage: T) => Promise<T>;
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  sendAndConfirmTransaction: ReturnType<typeof sendAndConfirmTransactionFactory>; // [!code ++]
  wallet: TransactionSigner & MessageSigner;
};

let client: Client | undefined;
export async function createClient(): Promise<Client> {
  if (!client) {
    // ...

    // 创建一个发送和确认交易的函数。 // [!code ++]
    const sendAndConfirmTransaction = sendAndConfirmTransactionFactory({ rpc, rpcSubscriptions }); // [!code ++]

    // 存储客户端。
    client = {
      estimateAndSetComputeUnitLimit,
      rpc,
      rpcSubscriptions,
      sendAndConfirmTransaction, // [!code ++]
      wallet,
    };
  }
  return client;
}
```

## 更新 `create-mint.ts`

现在，让我们在 `createMint` 函数中使用我们新的 `client.sendAndConfirmTransaction` 辅助函数。

剩下要做的就是返回我们创建的 `Mint` 帐户的地址，以便此函数的调用者可以将其用于进一步的操作。

这样，我们的 `createMint` 函数就完成了！

```ts twoslash title="src/create-mint.ts"
// @filename: client.ts
import {
  CompilableTransactionMessage,
  MessageSigner,
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
  TransactionSigner,
  sendAndConfirmTransactionFactory,
} from "@solana/kit";
export type Client = {
  estimateAndSetComputeUnitLimit: <T extends CompilableTransactionMessage>(transactionMessage: T) => Promise<T>;
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  sendAndConfirmTransaction: ReturnType<typeof sendAndConfirmTransactionFactory>;
  wallet: TransactionSigner & MessageSigner;
};
// @filename: create-mint.ts
// ---cut-before---
import {
  appendTransactionMessageInstructions,
  createTransactionMessage,
  generateKeyPairSigner,
  pipe,
  setTransactionMessageFeePayerSigner,
  setTransactionMessageLifetimeUsingBlockhash,
  signTransactionMessageWithSigners,
} from "@solana/kit";
import { getCreateAccountInstruction } from "@solana-program/system";
import { getInitializeMintInstruction, getMintSize, TOKEN_PROGRAM_ADDRESS } from "@solana-program/token";

import type { Client } from "./client";

export async function createMint(client: Client, options: { decimals?: number } = {}) {
  // 准备输入。
  const mintSize = getMintSize();
  const [mint, mintRent, { value: latestBlockhash }] = await Promise.all([
    generateKeyPairSigner(),
    client.rpc.getMinimumBalanceForRentExemption(BigInt(mintSize)).send(),
    client.rpc.getLatestBlockhash().send(),
  ]);

  // 构建指令。
  const createAccountIx = getCreateAccountInstruction({
    payer: client.wallet,
    newAccount: mint,
    space: mintSize,
    lamports: mintRent,
    programAddress: TOKEN_PROGRAM_ADDRESS,
  });
  const initializeMintIx = getInitializeMintInstruction({
    mint: mint.address,
    decimals: options.decimals ?? 0,
    mintAuthority: client.wallet.address,
    freezeAuthority: client.wallet.address,
  });

  // 构建交易消息。
  const transactionMessage = await pipe(
    createTransactionMessage({ version: 0 }),
    (tx) => setTransactionMessageFeePayerSigner(client.wallet, tx),
    (tx) => setTransactionMessageLifetimeUsingBlockhash(latestBlockhash, tx),
    (tx) => appendTransactionMessageInstructions([createAccountIx, initializeMintIx], tx),
    (tx) => client.estimateAndSetComputeUnitLimit(tx),
  );

  // 编译交易消息并签名。
  const signedTransaction = await signTransactionMessageWithSigners(transactionMessage);

  // 发送交易并等待确认。 // [!code ++]
  await client.sendAndConfirmTransaction(signedTransaction, { commitment: "confirmed" }); // [!code ++]

  // 返回已创建的 Mint 帐户的地址。 // [!code ++]
  return mint.address; // [!code ++]
}
```
