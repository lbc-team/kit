下表提供了一个 JavaScript 程序客户端列表，你可以将它们与 Kit 一起使用。请确保安装你的应用程序与之交互的每个程序的库，以访问其 API。

请注意，程序客户端是使用 [Codama](https://github.com/codama-idl/codama) 生成的，你也可以为你自己的程序客户端执行相同的操作。

| 程序仓库                                                                 | 库                                                                                                            | 维护者   |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ | ------------ |
| [地址查找表](https://github.com/solana-program/address-lookup-table)        | [`@solana-program/address-lookup-table`](https://www.npmjs.com/package/@solana-program/address-lookup-table) | [Anza][anza] |
| [计算预算](https://github.com/solana-program/compute-budget)                 | [`@solana-program/compute-budget`](https://www.npmjs.com/package/@solana-program/compute-budget)             | [Anza][anza] |
| [Memo](https://github.com/solana-program/memo)                                 | [`@solana-program/memo`](https://www.npmjs.com/package/@solana-program/memo)                                 | [Anza][anza] |
| [Token](https://github.com/solana-program/token)                               | [`@solana-program/token`](https://www.npmjs.com/package/@solana-program/token)                               | [Anza][anza] |
| [Token Extension](https://github.com/solana-program/token-2022)                | [`@solana-program/token-2022`](https://www.npmjs.com/package/@solana-program/token-2022)                     | [Anza][anza] |
| [Stake](https://github.com/solana-program/stake)                               | [`@solana-program/stake`](https://www.npmjs.com/package/@solana-program/stake)                               | [Anza][anza] |
| [System](https://github.com/solana-program/system)                             | [`@solana-program/system`](https://www.npmjs.com/package/@solana-program/system)                             | [Anza][anza] |

[anza]: https://www.anza.xyz/
