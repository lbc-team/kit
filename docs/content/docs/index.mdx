Kit 是一个 JavaScript SDK，用于构建跨 Node、Web 和 React Native 等环境的 Solana 应用程序。 它提供了一套全面的数据类型和辅助函数，为在 JavaScript 中与 Solana 交互奠定了基础。

<Callout title="来自 Web3.js?">
  查看我们的 [升级指南](/docs/upgrade-guide)，了解 Kit 与 Web3.js 的比较。
</Callout>

## 快速开始

按照以下简单步骤安装 Kit 并开始使用：

<Steps>
<Step>
 
### 安装 Kit

使用主 `@solana/kit` 库安装 Kit。 它包含许多较小的软件包，例如 `@solana/rpc` 或 `@solana/transactions`，这些软件包也可以单独使用，以实现更精细的导入。

```package-install
@solana/kit
```

</Step>

<Step>

### 安装程序客户端

为要交互的任何程序安装 Kit 兼容的客户端。 例如，要与 System 程序交互，请安装 `@solana-program/system` 包。 你可以在[此处找到可用程序客户端的列表](/docs/compatible-clients)。

```package-install
npm install @solana-program/system \
  @solana-program/memo \
  @solana-program/token \
  @solana-program/compute-budget
```

</Step>

<Step>

### 设置你的项目

使用 Kit 提供的原语来设置你的项目并开始与 Solana 交互！

例如，如果你计划发送交易，你可能需要一个 RPC API、一个 RPC 订阅 API 和一个“发送并确认”策略。

```ts twoslash
import { createSolanaRpc, createSolanaRpcSubscriptions, sendAndConfirmTransactionFactory } from "@solana/kit";

const rpc = createSolanaRpc("https://api.devnet.solana.com");
const rpcSubscriptions = createSolanaRpcSubscriptions("wss://api.devnet.solana.com");
const sendAndConfirmTransaction = sendAndConfirmTransactionFactory({ rpc, rpcSubscriptions });
```

查看我们的[入门](/docs/getting-started)教程和我们的[核心概念](/docs/concepts)指南，以了解有关如何使用 Kit 的更多信息。

</Step>
</Steps>
