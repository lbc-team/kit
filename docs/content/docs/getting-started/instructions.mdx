## 新的 token

现在我们的 `Client` 助手已经准备就绪，让我们用它来构建一个新的交易。在本教程中，我们将构建一个简单的交易，该交易使用 [Token program](https://github.com/solana-program/token) 创建一个新的 Solana token。

更准确地说，我们将创建一个 `Mint` 账户，该账户是代表 Solana token 的主要账户。我们需要至少两个指令来创建一个新的 `Mint` 账户：

- [System program](https://github.com/solana-program/system) 的 `CreateAccount` 指令。这将在 Solana 区块链上分配一个新账户，并将其分配给 Token program。
- [Token program](https://github.com/solana-program/token) 的 `InitializeMint` 指令。这将初始化先前分配的账户作为新的 `Mint` 账户。

## `createMint` 助手

在我们开始构建这些指令之前，让我们在 `src` 目录下创建一个新的 `create-mint.ts` 文件。我们将导出一个 `createMint` 函数，该函数将负责构建和发送创建新的 `Mint` 账户的交易。

我们将接受我们的 `Client` 对象作为第一个参数，并将一些选项作为第二个参数。为了简单起见，我们将仅支持自定义新 `Mint` 账户的小数位数。

```ts twoslash title="src/create-mint.ts"
// @filename: client.ts
import {
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
  TransactionSigner,
  MessageSigner,
} from "@solana/kit";
export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  wallet: TransactionSigner & MessageSigner;
};
// @filename: create-mint.ts
// ---cut-before---
import type { Client } from "./client";

export async function createMint(client: Client, options: { decimals?: number } = {}) {
  // ...
}
```

接下来，让我们开始在 `createMint` 助手函数中构建我们的指令。

## `CreateAccount` 指令

为了在 Solana 区块链上分配一个新账户，我们需要使用 System program 的 `CreateAccount` 指令。我们可以使用 `@solana-program/system` 库中的 `getCreateAccountInstruction` 助手函数来构建此指令。

```ts twoslash title="src/create-mint.ts"
// @filename: client.ts
import {
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
  TransactionSigner,
  MessageSigner,
} from "@solana/kit";
export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  wallet: TransactionSigner & MessageSigner;
};
// @filename: create-mint.ts
const payer = null as any;
const newAccount = null as any;
const lamports = null as any;
const space = null as any;
const programAddress = null as any;
// ---cut-before---
import { getCreateAccountInstruction } from "@solana-program/system";

import type { Client } from "./client";

export async function createMint(client: Client, options: { decimals?: number } = {}) {
  // Build instructions.
  // 构建指令
  const createAccountIx = getCreateAccountInstruction({
    payer,
    newAccount,
    space,
    lamports,
    programAddress,
  });
}
```

正如你所看到的，`getCreateAccountInstruction` 助手函数需要一些我们需要提供的输入：

- `payer` 签名者，他将支付新分配账户的存储费用。在我们的例子中，我们将使用 `Client` 对象的 `wallet` 签名者。
  ```ts twoslash
  import {
    Rpc,
    RpcSubscriptions,
    SolanaRpcApi,
    SolanaRpcSubscriptionsApi,
    TransactionSigner,
    MessageSigner,
  } from "@solana/kit";
  type Client = {
    rpc: Rpc<SolanaRpcApi>;
    rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
    wallet: TransactionSigner & MessageSigner;
  };
  const client = {} as Client;
  // ---cut-before---
  const payer = client.wallet;
  ```
- `newAccount` 本身作为签名者。由于这可以是任何地址，我们将生成一个新的地址，并将其保存为 `mint` 变量。
  ```ts twoslash
  import { generateKeyPairSigner } from "@solana/kit";
  const mint = await generateKeyPairSigner();
  ```
- 我们想要为新账户分配的 `space`。为此，我们可以使用 `@solana-program/token` 库中的 `getMintSize` 助手函数。
  ```ts twoslash
  import { getMintSize } from "@solana-program/token";
  const mintSize = getMintSize();
  ```
- 要转移到新账户以支付存储费用的 `lamports` 数量。这可以通过使用 `getMinimumBalanceForRentExemption` RPC 方法从我们想要为账户分配的大小中推断出来。此方法返回给定大小的账户所需的最小 lamports。
  ```ts twoslash
  import {
    Rpc,
    RpcSubscriptions,
    SolanaRpcApi,
    SolanaRpcSubscriptionsApi,
    TransactionSigner,
    MessageSigner,
  } from "@solana/kit";
  import { getMintSize } from "@solana-program/token";
  type Client = {
    rpc: Rpc<SolanaRpcApi>;
    rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
    wallet: TransactionSigner & MessageSigner;
  };
  const client = {} as Client;
  const mintSize = getMintSize();
  // ---cut-before---
  const mintRent = await client.rpc.getMinimumBalanceForRentExemption(BigInt(mintSize)).send();
  ```
- 将拥有新账户的程序的 `programAddress`。在我们的例子中，它是 Token program，其地址可以通过 `@solana-program/token` 库的 `TOKEN_PROGRAM_ADDRESS` 常量访问。
  ```ts twoslash
  import { TOKEN_PROGRAM_ADDRESS } from "@solana-program/token";
  const programAddress = TOKEN_PROGRAM_ADDRESS;
  ```

我们最终得到以下代码。请注意，我们如何将一些可以并行执行的 promise 包装在 `Promise.all` 中，以使代码更高效。

```ts twoslash title="src/create-mint.ts"
// @filename: client.ts
import {
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
  TransactionSigner,
  MessageSigner,
} from "@solana/kit";
export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  wallet: TransactionSigner & MessageSigner;
};
// @filename: create-mint.ts
// ---cut-before---
import { generateKeyPairSigner } from "@solana/kit";
import { getCreateAccountInstruction } from "@solana-program/system";
import { getMintSize, TOKEN_PROGRAM_ADDRESS } from "@solana-program/token";

import type { Client } from "./client";

export async function createMint(client: Client, options: { decimals?: number } = {}) {
  // Prepare inputs.
  // 准备输入
  const mintSize = getMintSize();
  const [mint, mintRent] = await Promise.all([
    generateKeyPairSigner(),
    client.rpc.getMinimumBalanceForRentExemption(BigInt(mintSize)).send(),
  ]);

  // Build instructions.
  // 构建指令
  const createAccountIx = getCreateAccountInstruction({
    payer: client.wallet,
    newAccount: mint,
    space: mintSize,
    lamports: mintRent,
    programAddress: TOKEN_PROGRAM_ADDRESS,
  });
}
```

## `InitializeMint` 指令

现在我们已经在链上分配了一个空账户，让我们将其初始化为 `Mint` 账户。为此，我们可以使用 `@solana-program/token` 库中的 `getInitializeMintInstruction` 助手函数。

```ts twoslash
const mint = null as any;
const decimals = null as any;
const mintAuthority = null as any;
const freezeAuthority = null as any;
// ---cut-before---
import { getInitializeMintInstruction } from "@solana-program/token";

const initializeMintIx = getInitializeMintInstruction({
  mint,
  decimals,
  mintAuthority,
  freezeAuthority,
});
```

这次，该指令要求我们提供以下输入：

- 我们刚刚分配的 `mint` 账户的地址。由于我们已经生成了一个新的 `mint` 签名者，我们只需要提供 `mint.address`。
- 新 `Mint` 账户的 `decimals` 数量。我们将使用 `options.decimals` 参数或默认为 `0`。
- 可以铸造新 token 的授权机构。在这里，我们将使用 `Client` 对象的 `wallet` 签名者。
- 可以冻结 token 的可选授权机构。让我们也使用 `wallet` 签名者。

我们最终得到以下代码：

```ts twoslash title="src/create-mint.ts"
// @filename: client.ts
import {
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
  TransactionSigner,
  MessageSigner,
} from "@solana/kit";
export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  wallet: TransactionSigner & MessageSigner;
};
// @filename: create-mint.ts
// ---cut-before---
import { generateKeyPairSigner } from "@solana/kit";
import { getCreateAccountInstruction } from "@solana-program/system";
import { getInitializeMintInstruction, getMintSize, TOKEN_PROGRAM_ADDRESS } from "@solana-program/token";

import type { Client } from "./client";

export async function createMint(client: Client, options: { decimals?: number } = {}) {
  // Prepare inputs.
  // 准备输入
  const mintSize = getMintSize();
  const [mint, mintRent] = await Promise.all([
    generateKeyPairSigner(),
    client.rpc.getMinimumBalanceForRentExemption(BigInt(mintSize)).send(),
  ]);

  // Build instructions.
  // 构建指令
  const createAccountIx = getCreateAccountInstruction({
    payer: client.wallet,
    newAccount: mint,
    space: mintSize,
    lamports: mintRent,
    programAddress: TOKEN_PROGRAM_ADDRESS,
  });
  const initializeMintIx = getInitializeMintInstruction({
    mint: mint.address,
    decimals: options.decimals ?? 0,
    mintAuthority: client.wallet.address,
    freezeAuthority: client.wallet.address,
  });
}
```

## 计算预算指令

除了我们可能需要在交易中使用的任何指令之外，我们还可以使用 Compute Budget program 中的指令来配置交易的计算分配。例如，我们可以使用 `SetComputeUnitLimit` 指令来设置我们的交易可以消耗的最大计算单元 (CU) 数量。该数字越低，我们的交易被包含在下一个区块中的机会就越高。此外，`SetComputeUnitPrice` 指令可用于以每个 CU 的微型 lamports 形式为我们的交易提供额外的优先级费用。

如果我们想在我们的交易中显式包含这些指令，我们可以使用 `@solana-program/compute-budget` 库中的 `getSetComputeUnitLimitInstruction` 和 `getSetComputeUnitPriceInstruction` 助手。

```ts twoslash
import { getSetComputeUnitLimitInstruction, getSetComputeUnitPriceInstruction } from "@solana-program/compute-budget";

const setComputeLimitIx = getSetComputeUnitLimitInstruction({
  units: 50_000, // 每次交易 50k CU。
  // 50k CUs per transaction.
});
const setComputePriceIx = getSetComputeUnitPriceInstruction({
  microLamports: 10_000, // 每个 CU 10k 微型 lamports，作为优先级费用。
  // 10k micro-lamports per CU, as priority fees.
});
```

但是，在本教程中，我们将不设置优先级费用，我们将使用另一个助手通过模拟来估计我们的交易将消耗的计算单元。我们将在下一篇文章中解决这个问题——以及交易消息构建。
