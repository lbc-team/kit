## 安装依赖

首先，使用 `src/index.ts` 文件设置一个新的 TypeScript 项目，并安装 `@solana/kit` 库。此外，为了使本教程专注于 Kit 库，我们将使用 `tsx` 来编译和运行我们的 TypeScript 代码。

```package-install
@solana/kit tsx
```

## 添加一些脚本

让我们也创建一个运行 `tsx src/index.ts` 的 `start` 脚本和一个启动本地 Solana 验证器的 `validator` 脚本。你的 `package.json` 应该如下所示：

```json
{
  "name": "kit-tutorial",
  "version": "1.0.0",
  "scripts": {
    "start": "tsx src/index.ts",
    "validator": "solana-test-validator"
  },
  "dependencies": {
    "@solana/kit": "^2.1.0",
    "tsx": "^4.19.3"
  }
}
```

从现在开始，我们只需要确保在使用 `start` 脚本之前，使用 `validator` 脚本运行一个 Solana 验证器。

## 创建一个客户端对象

为了简化我们的开发，我们将创建一个特定于我们应用程序的小型 `Client` 类型。这意味着它将包含与 Solana 交互所需的所有必要对象和函数。

我们需要的首先两件事是 RPC 和 RPC Subscriptions 对象，它们允许我们向网络发送请求并分别监听网络事件。我们需要它们来获取账户和发送交易。

让我们创建一个新的 `src/client.ts` 文件并添加以下 `Client` 类型：

```ts twoslash
import { Rpc, RpcSubscriptions, SolanaRpcApi, SolanaRpcSubscriptionsApi } from "@solana/kit";

export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
};
```

然后，让我们创建一个辅助函数来创建一个新的缓存 `Client` 对象，我们可以在整个应用程序中使用它：

```ts twoslash
import { Rpc, RpcSubscriptions, SolanaRpcApi, SolanaRpcSubscriptionsApi } from "@solana/kit";

export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
};
// ---cut-before---
import { createSolanaRpc, createSolanaRpcSubscriptions } from "@solana/kit";

let client: Client | undefined;
export function createClient(): Client {
  if (!client) {
    client = {
      rpc: createSolanaRpc("http://127.0.0.1:8899"),
      rpcSubscriptions: createSolanaRpcSubscriptions("ws://127.0.0.1:8900"),
    };
  }
  return client;
}
```

随着我们教程的进行，我们将向这个 `Client` 类型添加更多内容，但目前，这就是我们开始所需要的一切。

## 运行本教程

最后，让我们回到我们的 `src/index.ts` 文件并添加一个异步 `tutorial` 函数，我们将立即运行它来启动我们的教程。
现在，让我们只使用我们的 `Client` 对象来获取特定账户的余额。

我们可以通过 `address` 辅助函数创建一个 `Address` 类型，并通过 `rpc` 对象的 `getBalance` 方法获取余额来做到这一点。

```ts twoslash
// @filename: client.ts
import { Rpc, RpcSubscriptions, SolanaRpcApi, SolanaRpcSubscriptionsApi } from "@solana/kit";
export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
};
export function createClient(): Client {
  return {} as Client;
}
// @filename: index.ts
// ---cut-before---
import { address } from "@solana/kit";
import { createClient } from "./client";

// 运行本教程。
tutorial();

async function tutorial() {
  const client = createClient();
  const account = address("TokenzQdBNbLqP5VEhdkAS6EPFLC1PHnBqCXEpPxuEb");
  const { value: balance } = await client.rpc.getBalance(account).send();
  console.log(`Balance: ${balance} lamports.`);
}
```

现在，当你运行 `start` 脚本时，你应该会看到如下内容：

```
Balance: 1141440 lamports.
```
