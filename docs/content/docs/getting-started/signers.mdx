---
title: 生成签名者
description: 创建一个新的密钥对签名者并向其空投 lamports
---

在我们可以开始制作交易之前，我们需要一个可以签署交易并支付费用的钱包。在本文中，我们将探讨如何生成新的密钥对，以及如何在测试环境中向它们空投一些 lamports。

## 生成一个新的 `CryptoKeypair`

Kit 库使用 [原生 Crypto API](https://developer.mozilla.org/en-US/docs/Web/API/Crypto) 进行诸如生成密钥对以及签名或验证消息之类的密码学任务。 这通过利用浏览器内置函数而不是第三方库来提高安全性。

要创建新的密钥对，可以使用 `generateKeyPair` 辅助函数。 这将返回原生 `CryptoKeyPair` 类型的实例。

```ts twoslash
import { generateKeyPair } from "@solana/kit";

const wallet: CryptoKeyPair = await generateKeyPair();
```

就这样，我们有了一个可以用来签署交易的钱包。 但是，Kit 在任何可以签署消息和/或交易的内容之上提供了一个有用的抽象，称为 `Signers`。

## 生成一个新的 `KeyPairSigner`

使用 `CryptoKeyPairs` 是一种签名和验证交易的方式，但不是唯一的方式。 如果我希望我的交易由浏览器内钱包签名怎么办？ 如果我想使用硬件钱包对其进行签名怎么办？ 多重签名钱包呢？ 或者，如果我想要一些自定义逻辑来检测基于当前环境签署交易的最佳方式怎么办？

`Signer` API 允许我们通过提供可在整个库中使用的签名者接口，将签名逻辑与代码的其余部分分离。 `Signer` 是一个持有 `Address` 并为其消息和交易实现自己的签名逻辑的对象。

不同类型的签名者可用于各种用例，但在本教程中，我们将重点介绍 `KeyPairSigner`，它使用 `CryptoKeyPair` 签名交易和消息。 它实现了 `TransactionSigner` 和 `MessageSigner` 接口，因此任何需要交易或消息签名者的函数都可以使用它。

我们可以使用 `generateKeyPairSigner` 函数创建一个新的 `KeyPairSigner` 实例，如下所示。

```ts twoslash
import { generateKeyPairSigner } from "@solana/kit";

const wallet = await generateKeyPairSigner();
```

正如你所看到的，这与生成 `CryptoKeyPair` 非常相似，但现在我们有了一个抽象的 `Signer` 对象，可以在将来替换为任何其他类型的签名者，而不会影响我们代码的其余部分。

例如，以下是我们如何将 `KeyPairSigner` 替换为使用浏览器内钱包的签名者。

```ts twoslash
import { generateKeyPairSigner, KeyPairSigner, TransactionSigner } from "@solana/kit";
import { useWalletAccountTransactionSendingSigner } from "@solana/react";
// ---cut-start---
const account = null as unknown as Parameters<typeof useWalletAccountTransactionSendingSigner>[0];
const currentChain = null as unknown as Parameters<typeof useWalletAccountTransactionSendingSigner>[1];
// ---cut-end---

let wallet: TransactionSigner;
wallet = await generateKeyPairSigner(); // [!code --]
wallet = useWalletAccountTransactionSendingSigner(account, currentChain); // [!code ++]
```

要深入了解 Signer API，请查看 [这篇关于签名者的深入文章](/docs/concepts/signers)。

## 空投 lamports

现在我们知道如何生成新的签名者，让我们确保给它一些 lamports，以便它可以支付交易费用和帐户存储。 为此，我们可以使用 `airdropFactory` 函数。 给定一个 RPC 和 RPC 订阅对象，它将返回一个函数，该函数可用于向任何地址空投 lamports — 前提是我们处于本地网络等测试环境中。

```ts twoslash
import {
  airdropFactory,
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  generateKeyPairSigner,
  lamports,
} from "@solana/kit";

// 创建 RPC、RPC 订阅和空投函数。
const rpc = createSolanaRpc("http://127.0.0.1:8899");
const rpcSubscriptions = createSolanaRpcSubscriptions("ws://127.0.0.1:8900");
const airdrop = airdropFactory({ rpc, rpcSubscriptions });

// 生成一个具有 1 SOL 的新钱包。
const wallet = await generateKeyPairSigner();
await airdrop({
  recipientAddress: wallet.address,
  lamports: lamports(1_000_000_000n),
  commitment: "confirmed",
});
```

## 调整我们的 `Client` 对象

由于本教程的其余部分我们将依赖于此签名者，因此让我们调整我们的 `Client` 对象以包含它。

```ts twoslash title="src/client.ts"
import {
  createSolanaRpc,
  createSolanaRpcSubscriptions,
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
} from "@solana/kit";
// ---cut-before---
import { airdropFactory, generateKeyPairSigner, lamports, MessageSigner, TransactionSigner } from "@solana/kit";

export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  wallet: TransactionSigner & MessageSigner;
};

let client: Client | undefined;
export async function createClient(): Promise<Client> {
  if (!client) {
    // 创建 RPC 对象和空投函数。
    const rpc = createSolanaRpc("http://127.0.0.1:8899");
    const rpcSubscriptions = createSolanaRpcSubscriptions("ws://127.0.0.1:8900");
    const airdrop = airdropFactory({ rpc, rpcSubscriptions });

    // 创建一个带有 lamports 的钱包。
    const wallet = await generateKeyPairSigner();
    await airdrop({
      recipientAddress: wallet.address,
      lamports: lamports(1_000_000_000n),
      commitment: "confirmed",
    });

    // 存储客户端。
    client = { rpc, rpcSubscriptions, wallet };
  }
  return client;
}
```

请注意，我们必须使 `createClient` 函数异步，因为它现在包含用于生成 `KeyPairSigner` 并向其空投 lamports 的异步代码。 这意味着，我们还需要相应地调整我们的主 `tutorial` 函数。 在此期间，让我们显示我们新创建的钱包的余额。

```ts twoslash title="src/index.ts"
import {
  Rpc,
  RpcSubscriptions,
  SolanaRpcApi,
  SolanaRpcSubscriptionsApi,
  TransactionSigner,
  MessageSigner,
} from "@solana/kit";
export type Client = {
  rpc: Rpc<SolanaRpcApi>;
  rpcSubscriptions: RpcSubscriptions<SolanaRpcSubscriptionsApi>;
  wallet: TransactionSigner & MessageSigner;
};
export async function createClient() {
  return {} as Client;
}
// ---cut-before---
async function tutorial() {
  const client = await createClient();
  const { value: balance } = await client.rpc.getBalance(client.wallet.address).send();
  console.log(`Balance: ${balance} lamports.`);
}
```
